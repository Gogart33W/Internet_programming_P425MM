## 2. Специфікація моделі даних (`GameMode`)

Кожен ігровий режим представлений структурованим об'єктом із наступними обов'язковими полями:

| Поле | Тип | Опис та семантика | Правила валідації |
| :--- | :--- | :--- | :--- |
| `id` | `number` | Стабільний унікальний цілочисловий ідентифікатор | Ціле додатне число (`id > 0`, `Number.isInteger`) |
| `title` | `string` | Коротка назва ігрового режиму | Довжина від 3 до 80 символів після нормалізації пробілів |
| `category` | `string` | Жанрова категорія режиму | Дозволені значення: `'classic'`, `'sprint'`, `'survival'`, `'arcade'` |
| `speed` | `number` | Швидкість падіння фігур тетраміно (в мілісекундах) | Скінченне число (`Number.isFinite`), діапазон [30, 3000] мс |
| `scoreMultiplier` | `number` | Коефіцієнт нарахування очок за зібрані лінії | Скінченне число, діапазон [0.1, 10.0] |
| `isAvailable` | `boolean` | Прапорець доступності режиму для гравця (розблокований) | Строгий булевий тип (`typeof === 'boolean'`) |

## 3. Контракти функцій (`mode-service.js`)

### 3.1. Нормалізація та валідація

* **`normalizeTitle(value: any): string`**
  * *Призначення:* Обрізає зайві пробіли на початку та в кінці рядка, згортає послідовності пробільних символів `\s+` в один звичайний пробіл.
  * *Граничний випадок:* Якщо передано не рядок (`null`, `undefined`, число), безпечно повертає порожній рядок `""`.

* **`normalizeCategory(value: any): string`**
  * *Призначення:* Приводить рядок категорії до нижнього регістру та видаляє крайні пробіли.
  * *Граничний випадок:* Якщо вхідне значення не рядок, повертає `""`.

* **`validateMode(input: object): { isValid: boolean, errors: string[] }`**
  * *Призначення:* Повна перевірка об'єкта перед збереженням або оновленням.
  * *Контракт:* Не робить побічних ефектів (`console.log`), повертає об'єкт результату. `isValid` дорівнює `true` лише тоді, коли масив `errors` порожній.

* **`createMode(input: object, id: number): object | null`**
  * *Призначення:* Фабрична функція генерації стандартизованого екземпляра `GameMode`.
  * *Контракт:* У разі невалідного ID або непроходження валідації повертає `null`.

---

### 3.2. Пошук та фільтрація (чисті функції)

* **`findModeById(modes: GameMode[], id: number): GameMode | undefined`**
  * Використовує метод `Array.prototype.find`. Повертає знайдений запис або `undefined`, якщо режим із вказаним `id` не існує.

* **`filterByCategory(modes: GameMode[], category: string): GameMode[]`**
  * Використовує `Array.prototype.filter`. Порівняння проводиться з попередньою нормалізацією категорії.

* **`searchModesByTitle(modes: GameMode[], query: string): GameMode[]`**
  * Регістронезалежний пошук підрядка (`toLowerCase()`, `includes()`). Якщо `query` порожній рядок, повертає копію масиву `modes`.

* **`filterAvailableFastModes(modes: GameMode[], maxSpeed: number): GameMode[]`**
  * Комбінований фільтр за двома предикатами: `isAvailable === true && speed <= maxSpeed`.

* **`hasLockedModes(modes: GameMode[]): boolean`**
  * Метод `some`: перевіряє, чи є хоча б один заблокований режим (`!isAvailable`).

* **`allModesHaveValidSpeed(modes: GameMode[]): boolean`**
  * Метод `every`: перевіряє, що всі записи мають коректне числове значення швидкості.

---

### 3.3. Перетворення, агрегація та сортування

* **`getModeSummaries(modes: GameMode[]): Array<{id, title, category}>`**
  * Застосовує `map` та деструктуризацію для створення компактних DTO для інтерфейсу вибору.

* **`getFormattedLabels(modes: GameMode[]): string[]`**
  * Застосовує `map` для генерації готових для показу користувачу рядків із категорією, назвою, швидкістю та статусом доступу.

* **`calculateAverageSpeed(modes: GameMode[]): number`**
  * Використовує `reduce`. **Захист від Division by Zero:** Якщо масив порожній (`modes.length === 0`), повертає `0` замість `NaN`.

* **`countModesByCategory(modes: GameMode[]): Record<string, number>`**
  * Використовує `reduce` з початковим значенням `{}` для підрахунку частоти кожної категорії.

* **`sortModesByTitle(modes: GameMode[]): GameMode[]`**
  * Створює копію масиву `[...modes]` та сортує через `String.prototype.localeCompare(..., "uk")`. Початковий масив залишається незмінним.

* **`sortModesBySpeed(modes: GameMode[], ascending: boolean = true): GameMode[]`**
  * Числове сортування за властивістю `speed` без мутації джерела даних.

---

### 3.4. Незмінювані CRUD-операції (Immutability)

* **`addMode(modes: GameMode[], newMode: object): GameMode[]`**
  * Повертає `[...modes, Object.freeze({ ...newMode })]`.
  * Генерує виняток `Error`, якщо структура невалідна або режим із таким `id` вже існує в масиві.

* **`updateMode(modes: GameMode[], modeId: number, changes: object): GameMode[]`**
  * Здійснює незмінюване оновлення через `modes.map(...)`.
  * **Захист від несанкціонованої зміни ID:** Використовується деструктуризація `const { id: _ignoredId, ...safeChanges } = changes;`. Зміна `id` повністю ігнорується.
  * Якщо `modeId` не знайдено, повертає новий масив без модифікацій.

* **`removeMode(modes: GameMode[], modeId: number): GameMode[]`**
  * Видалення через `modes.filter(mode => mode.id !== modeId)`. Повертає новий масив меншої довжини.
