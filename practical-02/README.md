# Практична робота №2 — Миколайчук Микола, П-425

## Обґрунтування використання семантичних елементів:
- **`section`**: Використано для логічного поділу вмісту — окремо виділено ігрове поле, інформацію про наступну фігуру, рахунок та блок управління. Кожна секція має власний заголовок.
- **`aside`**: Застосовано для бічної ігрової панелі, оскільки цей блок містить допоміжну інформацію (рахунок, кнопки, підказки), яка доповнює головний процес на ігровому полі.
- **`div`**: Використано (клас `score-wrapper`) для технічного групування текстових елементів рахунку та рівня, де семантичні теги були б надлишковими.
- **`article`**: Не використано, оскільки на сторінці гри немає самодостатніх публікацій, новин чи карток, які можна було б виокремити як незалежний матеріал.
- **Відсутність таблиць (`<table>`)**: Макет не містить табличних даних (розкладів, тарифів тощо), тому таблиці навмисно не використовувалися. Ігрове поле реалізовано структурно без використання табличної верстки.
